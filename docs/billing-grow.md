# מנויים מתחדשים — מה מוכן ומה תלוי ב-Grow

מודל המנוי שאושר ב-17.10.2026:
1. חיוב ביום ההצטרפות.
2. חידוש אוטומטי כל חודש באותו תאריך (לפי שעון ישראל), עד ביטול.
3. ביטול עוצר את החידוש; המנוי בתוקף עד סוף התקופה ששולמה.
4. חיוב שנכשל — המנוי לא מוארך בלי אישור תשלום. אחרי 3 כישלונות החידוש נעצר.
5. אין חיוב כפול, וכל שינוי במנוי בתשלום נעשה רק לפי אירוע מאומת מ-Grow.
6. הלקוח רואה את תאריך החיוב הבא ויכול לבטל מתוך האפליקציה.

## מוכן ונבדק ב-Staging (בלי Grow ובלי חיובים)

| רכיב | קובץ |
|---|---|
| מסד: שדות חידוש במנוי, ניסיונות תשלום עם הסכמה, תשלומים (פעם אחת לכל עסקה), תור ביטולים מול Grow | `supabase/staging_secure/17_staging_billing.sql` |
| 83 בדיקות שרת עם אירועי Grow מדומים | `supabase/staging_secure/18_staging_billing_tests.sql` |
| מסך "המנוי שלי": תאריך וסכום החיוב הבא, ביטול עם אישור, הסכמה לתנאי החידוש לפני תשלום | `staging.html` |
| בדיקת דפדפן (25 בדיקות) | `scripts/staging_e2e/e2e_billing.py` |

פונקציות שרת:
- לאפליקציה: `hdm_billing_status()`, `hdm_billing_start_checkout(plan, terms_version, accept)`, `hdm_billing_cancel()`.
- לפונקציית השרת בלבד (service_role): `hdm_billing_apply_grow_event(event)`, `hdm_billing_attach_process(checkout, process_id)`,
  `hdm_billing_outbox_pending()`, `hdm_billing_outbox_done(id, ok, error)`.

רכישה באפליקציה כבויה (`HDM_BILLING_LIVE = false`). את מסך ההסכמה אפשר לבדוק ב-Staging עם `?billing=preview` — נשמרת הסכמה, בלי מעבר לתשלום ובלי חיוב.
`index.html` (האפליקציה הפעילה) ו-Production לא השתנו.

## תלוי בחיבור Grow
1. מפתחות API לסביבת בדיקות (sandbox), והפעלת Webhooks דרך התמיכה של Grow.
2. מ-Grow: איך מאמתים Webhook, ואיך מבטלים הוראת קבע דרך ה-API.
3. Edge Function `grow-checkout`: מקבלת ניסיון תשלום מהאפליקציה, יוצרת דף תשלום עם הוראת קבע חודשית, ומחזירה קישור.
4. Edge Function `grow-webhook`: מאמתת כל אירוע מול Grow, ורק אז קוראת ל-`hdm_billing_apply_grow_event`.
5. משימה מתוזמנת שמבצעת את תור הביטולים מול Grow (תוך פחות מ-3 ימי עסקים, כנדרש בחוק).
6. קבלה/חשבונית לכל חיוב (דרך Grow).
7. בדיקות מקצה לקצה בכרטיסי בדיקה של Grow, ואז `HDM_BILLING_LIVE = true` ב-Staging.
8. רק אחרי אישור: קובץ מעבר ל-Production, גיבוי, הרצה, והפעלה ב-`index.html`.

## החלטות פתוחות
- שדרוג/שנמוך באמצע חודש: עד שתתקבל החלטה, למנוי בתשלום פעיל אי אפשר לשנות מסלול (נחסם בשרת). אפשר לבטל ולהצטרף שוב אחרי סוף התקופה.
- סעיף מנויים בתנאי השימוש (חידוש, ביטול, החזרים, זכות ביטול 14 יום בעסקה מקוונת) — מומלץ שעורך דין יעבור עליו.
