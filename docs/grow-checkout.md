במסך "ניהול מנוי" — הכפתורים "בקרוב" הוחלפו ב"להצטרפות — ₪X לחודש", שמובילים לעמוד התשלום.

## בטיחות
- `HDM_CHECKOUT.live = false`: אין מעבר לתשלום ואין חיוב. אחרי האישור מוצגת הודעה שלא בוצע חיוב.
- רק קוד צד-לקוח. אין שינוי במסד, אין SQL, אין שינוי ב-Production עד מיזוג באישור מפורש.

## בדיקות
`python3 scripts/staging_e2e/e2e_checkout.py index.html` — 98 בדיקות (iPhone 13 ו-Desktop, שלושת המסלולים). כל בקשה ל-Supabase ול-Grow נחסמת בבדיקה.

## מה חסר מ-Grow כדי שכפתור התשלום יעביר לתשלום אמיתי
1. **פרטי חיבור לסביבת בדיקות (sandbox)**: מזהה משתמש/עסק ב-Grow (userId), קוד דף התשלום (pageCode) ומפתח API — יישמרו כסודות בשרת בלבד.
2. **אישור לחיוב חוזר / כרטיס שמור (טוקן)** — עד היום אושרה סליקה רגילה בלבד; מנוי מתחדש לא יעבוד בלעדיו.
3. **Webhook לאישור תשלום** (notifyUrl) ודרך לאמת שההודעה באמת מ-Grow.
4. **API לביטול הוראת חיוב ולהחזר כספי** — נדרש למדיניות הביטול.
5. כתובת החזרה אחרי תשלום (הצלחה/כישלון) — נגדיר אצלנו ונמסור ל-Grow.

אחרי שמתקבלים: חיבור דרך PR #32 (`hdm-billing-worker`) ← בדיקה מקצה לקצה ב-Staging מול ה-sandbox ← `HDM_CHECKOUT.live = true` — כל שלב באישור מפורש.
