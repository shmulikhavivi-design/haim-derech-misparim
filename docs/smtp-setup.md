# שליחת מיילים מקצועית (SMTP) ל-Supabase — מדריך לאייפון

**למה זה חוסם השקה:** בלי SMTP משלכם, Supabase שולח רק מספר קטן מאוד של מיילים, ורק לחברי הצוות של הפרויקט. משתמשים אמיתיים לא יקבלו מייל אישור הרשמה ולא מייל "שכחתי סיסמה". אחרי המעבר, "שכחתי סיסמה" הוא הדרך היחידה של חשבונות קיימים להתחבר לפרופיל שלהם.

**למה לא Gmail:** שירותי מייל מקצועיים כבר לא מאפשרים לשלוח בשם כתובת `@gmail.com`. Gmail ו-Yahoo דורשים שהשולח יהיה בעל הדומיין, אחרת המיילים נדחים או נוחתים בספאם. לכן את הגדרות ה-Gmail החלקיות **לא שומרים** (סעיף 0).

## ההמלצה: דומיין קטן + Resend
- **דומיין:** כ-10–12 דולר לשנה (כדאי לוודא מחיר בזמן הקנייה). לדוגמה `haimmisparim.com` או כל שם פנוי אחר.
- **Resend:** שירות שליחת מיילים עם מדריך רשמי ל-Supabase. המסלול החינמי מספיק להשקה: עד 3,000 מיילים בחודש ועד 100 ביום.
- **כתובת השולח:** `noreply@<הדומיין>`, בשם `חיים דרך מספרים`.
- **כתובת הקשר** בתוך המיילים נשארת `life.through.numbers333@gmail.com`. היא רק מופיעה בטקסט, לא שולחת.

## השלבים (כ-20 דקות, הכול מהאייפון)

### 0. ביטול הגדרות ה-Gmail החלקיות
Supabase ← הפרויקט **Haim Derech Misparim** ← Authentication ← Emails ← **SMTP Settings**:
- אם **Enable Custom SMTP** דלוק עם פרטי Gmail — מכבים אותו ולוחצים Save.
- חוזרים לכאן בשלב 4 וממלאים את פרטי Resend.

### 1. קניית דומיין
- באתר רשם דומיינים (למשל Cloudflare Registrar, שמוכר במחיר עלות ומנהל גם את ה-DNS באותו מקום).
- **לא צריך** אתר או תיבת מייל על הדומיין. הוא משמש רק לאימות השולח.

### 2. חשבון Resend ואימות הדומיין
1. נרשמים ב-resend.com.
2. **Domains ← Add Domain** ← מקלידים את הדומיין.
3. Resend מציג כמה רשומות DNS (TXT / MX). אם מוצעת הגדרה אוטומטית מול הרשם — משתמשים בה. אחרת מעתיקים כל רשומה ל-DNS של הדומיין אצל הרשם.
4. חוזרים ל-Resend ולוחצים **Verify**. האימות לוקח בדרך כלל כמה דקות.

### 3. מפתח SMTP
- Resend ← **API Keys ← Create API Key**, הרשאה **Sending access** בלבד.
- **המפתח הוא סיסמת ה-SMTP.** מעתיקים אותו ישר לשדה ב-Supabase (שלב 4). **לא שולחים אותו בצ'אט** ולא שומרים אותו ב-GitHub.

> **על החיבור האוטומטי Resend ↔ Supabase (Integrations):** הוא חוסך הקלדה, אבל מבקש גישה לארגון ב-Supabase. אם מסך ההרשאה מבקש גישת כתיבה לכל הארגון (כולל Production), כמו בפעם הקודמת — מוותרים עליו וממשיכים ידנית בשלב 4.

### 4. הגדרה ב-Supabase (Production)
Authentication ← Emails ← **SMTP Settings** ← Enable Custom SMTP:

| שדה | ערך |
|---|---|
| Sender email | `noreply@<הדומיין>` |
| Sender name | `חיים דרך מספרים` |
| Host | `smtp.resend.com` |
| Port | `465` |
| Username | `resend` |
| Password | המפתח משלב 3 |

לוחצים **Save**.

אחר כך: Authentication ← **Rate Limits** ← מגבלת המיילים לשעה. מעלים אותה ל-100 לפחות.

### 5. בדיקה
- באתר הפעיל (עדיין הגרסה הנוכחית): "שכחתי סיסמה" עם המייל שלכם.
- המייל צריך להגיע תוך דקה, מהשולח `noreply@<הדומיין>`, ולא לספאם.
- ב-Resend ← **Emails** רואים את המייל ואת הסטטוס שלו (Delivered).

### 6. Staging (לא חובה)
אותה הגדרה גם בפרויקט **Haim Derech Misparim Staging**, עם מפתח API נפרד. אפשר להשתמש באותו דומיין.

## רק אחרי שהבדיקה בשלב 5 עברה
Authentication ← Sign In / Providers ← Email ← להדליק **Confirm email**.
**הסדר חשוב:** אם מדליקים את Confirm email לפני שה-SMTP עובד, משתמשים חדשים לא יוכלו לסיים הרשמה.
