# לוח בקרה למנהל

## מה מוצג
- **משתמשים:**
  - סך הכול, גברים ונשים (מספר ואחוז).
  - חדשים היום, השבוע (מיום ראשון) והחודש.
  - פעילים ב-24 שעות וב-30 יום.
  - קבוצות גיל.
- **מנויים:**
  - מספר המשתמשים בכל מסלול (חינם / בסיסי / פלוס / VIP).
  - משלמים פעילים.
  - מסלולים שהוגדרו ידנית.
  - מנויים שבוטלו ומנויים שפג תוקפם.
- **הכנסות:**
  - רק מעסקאות מאומתות.
  - כל עוד אין מערכת תשלום מחוברת, מוצג "אין נתונים", ולא מספר.
  - MRR מחושב רק ממנויים משלמים.
- **פעילות:** 🎯, התאמות הדדיות, שיחות שנפתחו, דיווחים וחסימות.

## הגדרות
- **פעיל:** כניסה או רענון התחברות (session) בפועל בטווח הזמן.
- **הצטרפות:** תאריך יצירת משתמש ההתחברות. לפרופיל ישן בלי משתמש התחברות, לפי `createdAt` בפרופיל.
- **אזור הזמן:** "היום", "השבוע" ו"החודש" נמדדים לפי שעון ישראל.

## אבטחה
- **הרשאה:** רק חשבון שמופיע ב-`hdm_admins`.
  - הבדיקה נעשית בשרת, בתוך `hdm_admin_dashboard()`. משתמש רגיל שקורא ל-API מקבל `HDM_NOT_ADMIN`.
  - `hdm_admins` סגורה לגמרי ל-API.
  - מוסיפים או מסירים מנהל רק מ-SQL Editor. גם מנהל לא יכול לעשות זאת דרך האפליקציה.
- **מה חוזר מהשרת:** מספרים מצטברים בלבד. לא חוזרים שמות, אימיילים, מזהי פרופיל, תאריכי לידה או תוכן שיחות.
- **הלוח לקריאה בלבד:** אין בו כפתורים שמשנים נתונים.

## הפעלה ב-Production (אחרי ההשקה, באישור)
1. ב-SQL Editor של Production מריצים את `supabase/production/06_production_admin_dashboard.sql`.
2. באותו מקום מגדירים מנהל: `select public.hdm_admin_grant('<האימייל של חשבון המנהל>');`
3. ממזגים את ה-PR. הדף יהיה בכתובת:
   `https://shmulikhavivi-design.github.io/haim-derech-misparim/admin.html`
4. **באייפון:**
   - פותחים את הכתובת ב-Safari ונכנסים עם האימייל והסיסמה של חשבון המנהל. אם כבר מחוברים לאפליקציה באותו Safari, הלוח נפתח ישר.
   - לגישה מהירה: שיתוף ← "הוסף למסך הבית".
