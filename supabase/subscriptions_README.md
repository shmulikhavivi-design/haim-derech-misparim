# מערכת המנויים — התקנה ובדיקה

אין כאן שום חיוב. המסלולים מוגדרים ידנית מה-SQL Editor.

## סדר ההתקנה ב-Supabase (רק אחרי אישור)

1. `subscriptions.sql` — טבלאות ופונקציות. לא משנה שום התנהגות.
2. `subscriptions_test_accounts.sql` — מריצים פעם אחת כדי לראות את מזהי הפרופילים, ממלאים את המזהים של שמוליק, נועה, לימור ודני ומריצים שוב. כולם מקבלים פלוס (מנוי בדיקה).
3. `subscriptions_enforce.sql` — מפעיל את האכיפה בשרת.
4. `subscriptions_test.sql` — בדיקה אוטומטית. כל השורות צריכות להיות ✅. לא נשמר ממנה כלום.

ביטול: `subscriptions_rollback.sql` (חלק 1 מבטל רק את האכיפה; הנתונים נשמרים).

> אם האתר מתעדכן לפני הרצת ה-SQL, האפליקציה ממשיכה לעבוד בדיוק כמו היום, ומסך "המנוי שלי" מציג "בקרוב".

## החלפת מסלול לבדיקה

```sql
select public.hdm_admin_set_plan('<מזהה פרופיל>', 'free');   -- או basic / plus / vip
```

החלפת מסלול פותחת חודש חיוב חדש (מונה 5 השיחות מתאפס).

מנוי שפג (לבדיקת נעילה):

```sql
update public.hdm_subscriptions set current_period_end = now() - interval '1 minute' where profile_id = '<מזהה>';
```

ובסוף מחזירים: `select public.hdm_admin_set_plan('<מזהה>', 'plus');`

## רשימת בדיקה ידנית (באייפון)

**חינם**
- [ ] רואים פרופילים ותמונות.
- [ ] אין רמת התאמה ואין הסבר בכרטיס. מופיע "🔒 דירוג התאמה, 🎯 ושיחות — מהמסלול הבסיסי".
- [ ] לחיצה על 🎯 פותחת את מסך המנויים ולא שומרת עניין.
- [ ] בשיחות שלי: השיחות הקיימות מוצגות לקריאה, שליחה נעולה.

**בסיסי**
- [ ] מוצגת "התאמה מצוינת / טובה / חלשה" בלי הסבר.
- [ ] 🎯 חד-צדדי נשמר; 🎯 הדדי פותח צ׳אט.
- [ ] ב"השיחות שלי" מופיע "נותרו X מתוך 5". אחרי 5 שיחות חדשות, השישית לא נפתחת ומוצגת הודעה.
- [ ] בשיחות קיימות אפשר להמשיך לכתוב.

**פלוס**
- [ ] רמת התאמה + הסבר.
- [ ] "🎯 מי סימן אותי" מציג את מי שסימן; לחיצה פותחת את הכרטיס.
- [ ] כפתור "✨ ניתוח נומרולוגי מורחב" מופיע רק אחרי 🎯 הדדי.
- [ ] אין מגבלת שיחות.

**VIP**
- [ ] הניתוח המורחב נפתח מיד אחרי 🎯 שלי, גם בלי הדדיות.
- [ ] צ׳אט עדיין נפתח רק בהדדיות.
- [ ] במסך המנוי ובניתוח: הנחת 30% וכפתור אימייל (ו-WhatsApp אחרי שיוגדר מספר).

**מנוי שפג**
- [ ] ההודעות הישנות מוצגות; שדה הכתיבה נעול עם הודעה.

## מגבלות ידועות בשלב הזה

- האכיפה בשרת מתבססת על מזהה הפרופיל שבנתונים. התחזות לפרופיל אחר דרך ה-API תיחסם בשלב אבטחת טבלת `docs`.
- "מי סימן אותי" והניתוח המורחב מוגבלים בממשק בלבד, כי נתוני ה-🎯 ונתוני הלידה עדיין פתוחים לקריאה. ייסגר בשלב הסתרת נתוני הלידה.
- `HDM_LIMOR_WHATSAPP` ב-`index.html` ריק — צריך להוסיף את מספר הוואטסאפ של לימור.
- טקסטי הניתוח המורחב בנויים מהמשמעויות שכבר קיימות באפליקציה; כדאי שלימור תעבור עליהם.
