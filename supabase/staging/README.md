# סביבת הבדיקות (Staging) — מדריך לאייפון

הפרויקט האמיתי לא משתנה בשום שלב.
כל קובץ כאן בודק בשורה הראשונה שהוא רץ בפרויקט **Haim Derech Misparim Staging**, ואחרת נעצר בלי לשנות כלום.
קבצים שמשנים משהו רצים "הכול או כלום".

> **לפני כל הרצה:** בראש המסך ב-Supabase צריך להיות כתוב **Haim Derech Misparim Staging**.

## איך מריצים קובץ (אותה פעולה לכל קובץ)

1. ב-GitHub פותחים את הקובץ ולוחצים על כפתור ההעתקה (Copy raw file).
2. ב-Supabase: תפריט ← **SQL Editor** ← **New query**.
3. מדביקים ולוחצים **Run**.
4. מצלמים את התוצאה ושולחים לי.

## חשבונות הבדיקה (הרשמה באפליקציית הבדיקות)

אפליקציית הבדיקות מסומנת בפס סגול **"🧪 סביבת בדיקות"** בראש המסך.
נרשמים ארבע פעמים. **השם שקוראים לך היום** חייב להיות בדיוק:

- `בדיקה חינם`
- `בדיקה בסיסי`
- `בדיקה פלוס`
- `בדיקה VIP`

**אימייל:** אפשר להשתמש בכתובת ה-Gmail שלך עם תוספת, למשל `name+free@gmail.com` או `name+basic@gmail.com`. כל המיילים יגיעו לאותה תיבה.

**תאריך לידה ושם מלידה:** כל ערך מומצא, מעל גיל 18.

## רשימת בדיקה ידנית

אחרי שלב 5, מתחברים לכל חשבון ובודקים.

**התאמות ונומרולוגיה (כל המסלולים)**
- [ ] הכרטיסים מציגים את הפרופילים המומצאים, עם מספר דרך החיים בעיגול.
- [ ] החלקה בין כרטיסים עובדת.

**חינם**
- [ ] אין רמת התאמה ואין הסבר. מופיע 🔒.
- [ ] לחיצה על 🎯 פותחת את מסך המנויים.
- [ ] "השיחות שלי" מציג שהשליחה נעולה.

**בסיסי**
- [ ] מופיעה "התאמה מצוינת / טובה / חלשה", בלי הסבר.
- [ ] 🎯 על פרופיל בדיקה אחר (למשל פלוס) מציג "העניין נשמר".
- [ ] אחרי שגם הצד השני לוחץ 🎯, נפתח צ׳אט.
- [ ] הודעות עוברות בשני הכיוונים.
- [ ] ב"השיחות שלי" מופיע "נותרו X מתוך 5".

**פלוס**
- [ ] רמת התאמה + הסבר.
- [ ] "🎯 מי סימן אותי" מציג את מי שסימן.
- [ ] "✨ ניתוח מורחב" מופיע רק אחרי 🎯 הדדי.

**VIP**
- [ ] הניתוח המורחב נפתח מיד אחרי 🎯 שלי.
- [ ] צ׳אט נפתח רק בהדדיות.
- [ ] במסך "המנוי שלי": הנחת 30% וכפתור אימייל.

**כללי**
- [ ] התחברות, יציאה והתחברות מחדש.
- [ ] עריכת פרופיל.
- [ ] חסימה ודיווח.
- [ ] איפוס סיסמה.
